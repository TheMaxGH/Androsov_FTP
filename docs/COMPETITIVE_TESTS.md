# Сравнительные тесты с аналогами

Документ описывает тесты, которые показывают отличие VALLHALA FTP от популярных аналогов: FileZilla Client/Server, WinSCP, IIS FTP и vsftpd. Это не таблица фактических замеров, а методика для дипломного сравнения: что запускать, что фиксировать и какой вывод делать.

## Тестовое окружение

| Параметр | Значение |
| --- | --- |
| ОС клиента | `Windows, версия` |
| ОС сервера | `Windows/Linux, версия` |
| Python | `python --version` |
| Сеть | `localhost / LAN 1 Gbit / Wi-Fi` |
| Тестовая папка | `D:\Share` |
| Тестовый файл | `100 MB`, `1 GB`, набор `100 x 64 KB` |
| Протоколы | `FTP`, `FTPS` |
| Аналоги | `FileZilla Server`, `FileZilla Client`, `WinSCP`, `IIS FTP`, `vsftpd` |

## Матрица отличий

| Критерий | VALLHALA FTP | FileZilla Client/Server | WinSCP | IIS FTP / vsftpd | Что доказывает тест |
| --- | --- | --- | --- | --- | --- |
| Единое приложение | GUI, CLI и headless server в одном проекте | Клиент и сервер разделены | В основном клиент | Серверная роль или демон | Ниже порог входа для учебного и LAN-сценария |
| Быстрый запуск сервера | Сервер запускается из GUI или одной CLI-командой | Нужна отдельная установка и настройка сервера | Сервер не предоставляет | Требуется настройка ОС/службы | Быстрее путь от установки до работающего FTP |
| Несколько серверов | Несколько профилей в одном GUI и JSON-конфиге | Обычно отдельная серверная конфигурация | Не сервер | Несколько инстансов/конфигов | Удобнее демонстрировать разные режимы доступа |
| LAN discovery | Встроенный сканер портов `21` и `2121` | Обычно ручной ввод адреса | Обычно ручной ввод адреса | Нет desktop discovery | VALLHALA помогает найти сервер в локальной сети |
| Учебная прозрачность | Код на Python, понятные слои `core`, `infrastructure`, `presentation` | Готовый продукт | Готовый продукт | Системный сервис | Проект проще анализировать, расширять и защищать |
| CLI automation | `--legacy-server` и `--ftp list/upload/download` | Зависит от отдельного инструмента | Сильный scripting | Сервисные команды ОС | Есть автоматизация без отказа от GUI |

| UX для новичка | Русский GUI, статусы, профили, быстрые сценарии | Много настроек | Сильный клиентский UX | Нет единого desktop GUI | Ниже сложность первичной настройки |

## Как формулировать вывод в дипломе

VALLHALA FTP не конкурирует с промышленной зрелостью FileZilla Server, WinSCP, IIS FTP или vsftpd. Отличие проекта в другом: он объединяет FTP/FTPS-сервер, FTP/FTPS-клиент, GUI, CLI, LAN-discovery, профили серверов и учебно понятную архитектуру в одном приложении. Сравнительные тесты должны показывать не только скорость передачи, но и удобство запуска, количество ручных действий, наличие автоматизации и прозрачность реализации.
