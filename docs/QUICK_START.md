# Быстрый старт

## 1. Установка

```powershell
python -m pip install -r requirements.txt
```

## 2. Запуск GUI

```powershell
python main.py
```

## 3. Поднять сервер за пару минут

1. Откройте вкладку **Серверы**.
2. Выберите профиль `Default` или нажмите **Добавить**.
3. Укажите папку раздачи.
4. Добавьте пользователей или включите `anonymous read-only`.
5. Нажмите **Запустить**.
6. Скопируйте адрес из live-карточки, например `ftp://192.168.1.178:2121`.

## 4. Подключиться клиентом

На вкладке **Проводник** укажите host, port, login/password и нажмите **Подключиться**.

Файлы можно перетаскивать прямо в локальный проводник приложения: они попадут в очередь загрузки.

## 5. Если сервер не запускается

- Проверьте статус на live-карточке.
- Если порт занят, выберите другой порт.
- Если включен FTPS, проверьте путь к сертификату и ключу.
- Если подключение идет с другой машины, проверьте firewall и passive range.
