# Performance tests

Эта таблица фиксирует базовый набор тестов производительности для VALLHALA FTP. Перед прогоном укажите окружение, чтобы результаты можно было сравнивать между версиями.

## Окружение прогона

| Параметр | Значение |
| --- | --- |
| Дата прогона | `YYYY-MM-DD` |
| ОС | `Windows/Linux/macOS, версия` |
| Python | `python --version` |
| Сеть | `localhost / LAN 1 Gbit / Wi-Fi` |
| Диск | `SSD / HDD / network share` |
| Протокол | `FTP / FTPS` |
| Конфиг сервера | `vallhala.servers.json` или параметры CLI |

## Таблица тестов

| ID | Сценарий | Команда или методика | Данные | Метрики | Целевой ориентир | Примечания |
| --- | --- | --- | --- | --- | --- | --- |
| PERF-001 | Холодный старт GUI | `Measure-Command { python main.py }` и ручная фиксация времени до готового окна | Без запущенных серверов | Время запуска, пиковая память | Окно готово до 3 с на рабочей машине | Проверять после чистой установки зависимостей |
| PERF-002 | Старт headless FTP-сервера | `Measure-Command { python main.py --legacy-server --host 127.0.0.1 --port 2121 --root "D:\Share" --user user --password password }` | Пустая root-папка | Время до открытия порта, ошибки запуска | Порт слушает до 1 с | Команду останавливать вручную после проверки |
| PERF-003 | LAN-сканирование `/24` | В GUI запустить сканер или вызвать `FastLANScanner(timeout=0.18, concurrency=128).scan_sync()` | Подсеть `/24`, порты `21`, `2121` | Общее время, найденные узлы, отсутствие зависания UI | До 10 с для `/24` при стандартном timeout | Сравнивать при одинаковом timeout и concurrency |
| PERF-004 | Загрузка маленьких файлов | Через CLI или GUI загрузить 100 файлов по 64 KB | 100 файлов, общий объем около 6.4 MB | Файлов/с, средняя задержка операции, ошибки | Без ошибок и заметной деградации UI | Хорошо выявляет накладные расходы на много операций |
| PERF-005 | Загрузка среднего файла | `python main.py --ftp upload --host 127.0.0.1 --port 2121 --user user --password password --local ".\perf\100mb.bin" --remote 100mb.bin` | 100 MB | MB/s, время, CPU, память | Скорость близка к лимиту диска/сети localhost | Для генерации файла: `fsutil file createnew .\perf\100mb.bin 104857600` |
| PERF-006 | Скачивание среднего файла | `python main.py --ftp download --host 127.0.0.1 --port 2121 --user user --password password --remote 100mb.bin --local ".\perf\downloaded.bin"` | 100 MB | MB/s, время, целостность файла | Скорость близка к upload на том же окружении | После теста сравнить размер и хэш файла |
| PERF-007 | Большой файл | Upload и download файла 1 GB через CLI | 1 GB | MB/s, стабильность, память, ошибки | Память не растет пропорционально размеру файла | Проверяет буферизацию `_buffer_for_size` |
| PERF-008 | Параллельные клиенты | Запустить 4-8 одновременных upload/download процессов | 4-8 клиентов, файлы 100 MB | Суммарная скорость, ошибки, активные сессии | Сессии учитываются корректно, сервер не падает | Учитывать `max_connections` и `max_connections_per_ip` |
| PERF-009 | Лимиты скорости | Включить `upload_limit_kbps` и `download_limit_kbps` в профиле | Файл 100 MB | Фактическая скорость, отклонение от лимита | Скорость близка к заданному лимиту | Допустимы небольшие колебания из-за буферов |
| PERF-010 | FTPS overhead | Повторить PERF-005 и PERF-006 с `protocol: "ftps"` | 100 MB, TLS-сертификат | Разница FTP/FTPS по скорости и CPU | FTPS работает стабильно без обрывов | Нужен установленный `pyOpenSSL` |
| PERF-011 | Долгая работа сервера | Оставить сервер под периодическими list/upload/download на 1-2 часа | Малые и средние файлы | Ошибки, память, активные сессии | Нет утечек памяти и зависших сессий | Полезно перед production-развертыванием |
| PERF-012 | Стресс на лимит подключений | Создать больше клиентов, чем `max_connections_per_ip` | Много коротких соединений | Корректные отказы, стабильность сервера | Лишние подключения отклоняются без падения | Проверять логи событий сервера |
